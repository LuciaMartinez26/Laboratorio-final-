# Sistema Web Inteligente para la Gestión Académica

## Descripción General
Aplicación web desarrollada para la gestión académica estudiantil, control de notas, administración de usuarios y generación de estadísticas en tiempo real.

## Tecnologías Utilizadas
* HTML5 / CSS3
* JavaScript ES6+ (POO, Manipulación del DOM, Cookies y Web Storage)
* GitHub para control de versiones
* Netlify para el despliegue
